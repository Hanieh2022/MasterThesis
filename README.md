# Master's Thesis
My thesis titled "AI Technologies and Workforce Skills: Analysis of Repeated Cross-Sectional Surveys (2018–2022)" was conducted using R. Methodologically, the Work Complexity Index (WCI) was adapted and further developed using data from the Finnish Working Life Barometer (FWLB) and Factor Analysis method.
